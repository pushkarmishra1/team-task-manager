# Team Task Manager

A full-stack web app to manage team tasks with role-based access.

## Features
- Authentication (JWT)
- Task creation & assignment
- Dashboard with overdue tasks
- Role-based users (Admin/Member)

## Tech Stack
- Frontend: React (Vite)
- Backend: Node.js, Express
- Database: MongoDB
